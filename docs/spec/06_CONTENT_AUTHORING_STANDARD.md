# Content Authoring Standard

## 1. Purpose

This document ensures that lessons and questions remain consistent across authors, developers, and AI-assisted workflows.

## 2. Lesson Template

Every lesson must contain:

1. Skill title
2. Learning objective
3. Prerequisite reminder
4. Intuitive explanation
5. Concrete or visual representation
6. Formal terminology
7. Worked example 1
8. Worked example 2
9. Guided practice
10. Independent practice
11. Transfer problem
12. Common mistakes
13. Summary
14. Review prompt

## 3. Explanation Style

Explanations must:

- Use plain language first
- Define new terms before relying on them
- Avoid unexplained notation
- Explain why a method works
- Use short logical steps
- Distinguish rules from examples
- Avoid unnecessary stories or decorative text
- Use age-neutral language
- Avoid assuming prior school success

## 4. Worked Examples

Each worked example must include:

- Problem
- Goal
- Step-by-step solution
- Reason for each step
- Final answer
- Quick verification when possible

## 5. Question Metadata

Each question must define:

- Question ID
- Skill ID
- Question type
- Difficulty
- Prompt
- Structured parameters
- Correct answer
- Accepted equivalent answers
- Validator
- Hint ladder
- Common wrong answers
- Error mappings
- Explanation
- Estimated time
- Transfer status
- Accessibility text

## 6. Difficulty Levels

### Level 1

Direct recognition or one-step application.

### Level 2

Routine application with simple values.

### Level 3

Multi-step or mixed representation.

### Level 4

Unfamiliar context or distractors.

### Level 5

Transfer, synthesis, or explanation.

## 7. Hint Standard

Hints must progress from least revealing to most revealing.

A hint should never introduce a new unexplained method.

## 8. Misconception Records

Each misconception must include:

- Misconception ID
- Description
- Detection rule
- Example wrong answer
- Corrective explanation
- Recommended prerequisite check
- Follow-up question

## 9. Mathematical Notation

- Use conventional notation
- Provide accessible text equivalents
- Preserve exact values unless approximation is requested
- Label units
- Specify rounding rules
- Accept mathematically equivalent forms when appropriate

## 10. Science Content

Scientific content must distinguish:

- Observation from inference
- Correlation from causation
- Measurement from interpretation
- Accuracy from precision
- Evidence from conclusion
- Model from reality

## 11. Content Validation

Before publication, every content item must pass:

- Factual review
- Validator review
- Prerequisite review
- Accessibility review
- Difficulty review
- Misconception review
- Rendering review
