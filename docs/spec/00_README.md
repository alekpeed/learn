# Ground-Up Learning App Documentation Package

This package defines the first complete build of a mastery-based educational application.

Initial curriculum scope:

- Mathematics from basic arithmetic through introductory algebra
- Scientific reasoning and measurement

The documents are coder-agnostic. They define product behavior, educational logic, interfaces, data, quality standards, and development order without assuming a particular coding assistant, programming language, framework, or hosting provider.

## Source of Truth

When documents conflict, use this priority:

1. Product requirements
2. Version and scope plan
3. Learning system specification
4. Curriculum architecture
5. Technical architecture
6. Implementation backlog

Any unresolved conflict must be recorded in the decision log before implementation continues.
