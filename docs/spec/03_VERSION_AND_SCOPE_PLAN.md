# Version and Scope Plan

## MVP Objective

Deliver a complete, usable learning engine with enough mathematics content to prove the educational model.

## MVP Curriculum

### Mathematics

1. Number sense
2. Place value
3. Addition
4. Subtraction
5. Multiplication
6. Division
7. Order of operations
8. Factors and multiples
9. Negative numbers
10. Fractions
11. Decimals
12. Percentages
13. Ratios and proportions
14. Basic measurement
15. Variables
16. Expressions
17. One-step equations
18. Two-step equations
19. Coordinate plane
20. Basic graphs
21. Introductory functions

### Scientific Reasoning and Measurement

1. Observation versus inference
2. Questions and hypotheses
3. Variables and controls
4. Measurement
5. SI units
6. Unit conversion
7. Accuracy and precision
8. Estimation
9. Significant figures at an introductory level
10. Tables
11. Graph selection
12. Graph interpretation
13. Proportional reasoning in science
14. Experimental error
15. Drawing evidence-based conclusions

## MVP Features

- Local learner profile
- Optional diagnostic
- Skill dependency graph
- Lessons
- Guided practice
- Independent practice
- Progressive hints
- Deterministic answer validation
- Skill mastery tracking
- Spaced review queue
- Curriculum map
- Basic AI tutor integration
- Local-first persistence
- Exportable learner progress
- Accessibility baseline
- Automated core tests

## Version 1 Features

Version 1 includes the MVP plus:

- Cloud account and synchronization
- Cross-device resume
- Expanded question types
- Improved misconception diagnosis
- Content administration interface
- Richer visualizations
- AI-generated practice drafts requiring validation
- User notes
- Study plans and daily targets
- Downloadable course modules

## Later Features

- Geometry
- Algebra II
- Statistics and probability
- Physics
- Chemistry
- Biology
- Multi-user support
- Teacher dashboards
- Classrooms
- Social features
- Gamification systems
- Voice tutoring
- Handwriting recognition
- Fully interactive scientific simulations
- Marketplace or community-authored courses

## Explicitly Excluded From MVP

- Competitive leaderboards
- Public profiles
- Real-time multiplayer
- Teacher classroom management
- Full content marketplace
- Fully AI-generated curriculum
- AI-only grading
- Complex social systems
- Native applications for every platform
- Advanced science courses
- Advanced symbolic proof systems

## Completion Rule

The MVP is complete only when the entire scoped curriculum can be traversed through prerequisites, lessons, practice, mastery checks, and review. A collection of disconnected demo screens does not count as completion.
